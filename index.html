How to Install Ubuntu on Mobile

Termux Guide • By Bhut Herit • 4 min read
Install Termux

Download the latest Termux APK from F-Droid — avoid the Play Store version as it's outdated and unmaintained.

Update Termux Packages

Sync repositories to the latest versions.

pkg update && pkg upgrade -y
Install PRoot-Distro

This utility manages Linux environments without root access.

pkg install proot-distro -y
Install Ubuntu

Install Ubuntu inside Termux.

proot-distro install ubuntu
Launch Ubuntu

Enter your Ubuntu environment.

proot-distro login ubuntu
Update Ubuntu System

Update Ubuntu packages.

apt update && apt upgrade -y

How to Install VSCode on Mobile

Code-Server Guide • By Bhut Herit • 5 min read
Launch Your Linux Environment

Open Termux and log into Ubuntu or Debian.

proot-distro login ubuntu
Install Required Tools

Install curl.

apt update && apt install curl -y
Install Code-Server

Install Code-Server.

curl -fsSL https://code-server.dev/install.sh | sh
Start the VSCode Server

Launch Code-Server.

code-server --bind-addr 127.0.0.1:8080
Open in Your Mobile Browser

Open your browser and navigate to:

http://localhost:8080
Enter Your Password

Find the generated password.

cat ~/.config/code-server/config.yaml

How to Install Debian on Mobile

Debian Guide • By Bhut Herit • 4 min read
Open Termux & Update

Refresh Termux packages.

pkg update -y
Install PRoot-Distro

Install the Linux environment manager.

pkg install proot-distro -y
Install Debian

Install Debian.

proot-distro install debian
Boot into Debian

Enter Debian.

proot-distro login debian
Install Dev Tools

Install Git, Curl and build tools.

apt update && apt install git curl build-essential -y
You're Done!

You now have a clean Debian environment running directly on Android.
